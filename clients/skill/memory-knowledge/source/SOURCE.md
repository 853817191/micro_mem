# 素材准备指南（S0）

> 蒸馏协议的上游：把**任意能转成文字的输入**标准化为锚点（turn 序列），
> 经**确认闸门**核对后落库。蒸馏全链路（S2 供给 / S3 轮次标注 / S6 回读）
> 只消费锚点里的 `── turn N ──` 结构——素材质量在此一步定生死。
> 机制归系统（parsers），判断归本文。

## 1. 输入通道（五种）

| 输入 | 命令 | 切轮规则 |
|---|---|---|
| Claude 会话 jsonl | `mem anchor <路径>`（缺省取最新会话） | 按 user 发言切轮（含其后的 assistant/tool 过程） |
| md 文档 | `mem anchor <路径>` | 按 `#` / `##` 标题切轮；无标题整篇 1 轮 |
| 本地 html | `mem anchor <路径>` | 去标签（script/style 跳过），按 h1-h3 切轮 |
| http(s) URL | `mem anchor <URL>` | 抓取后同 html 规则 |
| 对话里直接贴的描述 | `mem anchor --text "..."` | 整段 1 轮 |

格式自动探测（URL → md → html → jsonl），`--preview` 视图里会标明实际切了几轮。
多段、有结构的描述**不要**用 `--text`——写成 md 文件走标题切轮，轮次粒度才是
蒸馏 turns 标注 / 游标增量能用的粒度。

## 2. 确认闸门（两步，缺一不可）

```bash
mem anchor <输入> --preview   # ① 只渲染【素材确认】视图，不落库
                              #    核对：轮次切分对不对 / 内容全不全 / 有无乱码
mem anchor <输入>             # ② 核对无误后执行：正式落库
```

发现遗漏/偏差：修正源内容后重新 ①，直到视图正确再 ②。
**禁止跳过 preview 直接落库**——素材错了，后面四轮协议全在错料上跑。

## 3. 素材纪律（防污染，血泪条款）

1. **只依据素材**：计划项 gist/正文里的事实，必须能在 `source.turns` 标注的
   轮次原文里找到。凭记忆、凭上轮讨论、凭代码走查印象写进去的事实 =
   污染（本会话真实发生过：把代码核实产物混进计划，structure 轴凭空建出）。
2. **代码核实产物走素材通道**：读代码确认的事实（真实状态机、表结构、入口归属），
   先整理成文本（`--text` 或 md 文件）**重新 anchor 进素材**，再蒸馏——
   让核实过程留痕、可审、可被 R3 回读。
3. **确认视图里每轮都要过目**：轮次边界错（两段主题被切进同一轮 / 一段被腰斩）、
   乱码（html 编码误判）、内容截断，都是必须在闸门处拦下的问题。
